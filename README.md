# 🍽️ Restaurant Ordering & Management System

## 📌 Overview

The Restaurant Ordering & Management System is a console-based application developed using C++. It allows users to browse food categories, select menu items, manage their shopping cart, and complete orders through a checkout system.

This project was created to practice Object-Oriented Programming (OOP), arrays, loops, conditional statements, switch cases, and input validation in C++.

## ✨ Features

* **Interactive Main Menu:** Navigate between main courses, desserts, cart management, checkout, and exit options.
* **Food & Dessert Selection:** Choose from multiple food items with different prices.
* **Shopping Cart:** Add items and track their quantities and prices.
* **Duplicate Item Handling:** Automatically increase the quantity when an existing item is selected again.
* **View Cart:** Display selected items, quantities, and subtotal.
* **Remove Items:** Remove a selected quantity or delete an item entirely.
* **Clear Cart:** Empty the shopping cart with a confirmation step.
* **Checkout System:** Display an order summary, calculate 14% tax, and calculate the final total.
* **Payment Validation:** Check payment input and prevent checkout when the payment is insufficient.
* **Change Calculation:** Calculate the remaining balance after payment.
* **Order ID:** Assign a unique sequential order number to each completed order.
* **Input Validation:** Handle invalid menu selections and incorrect quantity inputs.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio or another C++ IDE.
3. Compile and run the source code.
4. Use the console menu to navigate through the system.

## 🎯 Project Goals

This project demonstrates fundamental C++ programming skills through a practical restaurant ordering application. It also provides experience in managing arrays, organizing code inside a class, validating user input, and implementing a checkout workflow.
